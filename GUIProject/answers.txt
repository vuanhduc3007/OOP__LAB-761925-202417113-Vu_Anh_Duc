Question: What happens when you don't update for them to catch?
Answer: If an exception is thrown but not caught anywhere in the program, it will propagate up the call stack. If it reaches the main() method and is still uncaught, the Java Virtual Machine (JVM) will unexpectedly terminate the program and print the stack trace to the console. In a GUI application like JavaFX, this can cause the application to freeze, behave unpredictably, or crash completely without providing any friendly error message to the user.
